# Oh My Toilet — 토스 앱인토스 출시 준비 점검

> 기준일: 2026-08-14 · 대상 플랫폼: 토스 앱인토스(미니앱) → 이후 구글 플레이
> 참고: [앱인토스 서비스 오픈 정책](https://developers-apps-in-toss.toss.im/intro/guide) · [서비스별 주의사항](https://developers-apps-in-toss.toss.im/intro/caution)

앱인토스는 계약 없이 개인 개발자도 출시 가능(평균 5일 심사). 아래는 우리 앱 기준 현황.

---

## ✅ 이미 된 것

- **핵심 UX**: 리스트(거리순) · 지도 · 즐겨찾기 · 필터(장애인/개방중) · 제보(생성·열람·삭제) · 시니어 큰글씨
- **실데이터**: 전국 6,784곳 번들 (제천 개방화장실 42곳 이름·개방시간·전화 온전)
- **위치기반사업 신고 완료** (앱인토스 위치서비스의 법적 전제)
- 매 기능 tsc + expo export 검증

## 🚧 출시 전 필수 (Blocker)

| # | 항목 | 내용 | 근거 |
|---|---|---|---|
| B1 | **번들 용량** | 현재 ~10MB (Metro가 91개 지역타일 JSON을 전부 번들에 포함). 미니앱은 용량 민감 → **핵심 지역만 번들 + 나머지 원격 fetch**, 또는 데이터 전량 원격화 필요 | 이미 알려진 이슈(타일링 커밋에서 플래그됨) |
| B2 | **외부 앱 링크** | 길찾기가 **카카오맵(외부 앱)** 을 여는데, 앱인토스는 "외부 링크·앱 설치 유도"를 제한적으로만 허용 → 인앱 지도 처리 or 정책 확인 필요 | 앱인토스 오픈 정책 §외부 링크 제한 |
| B3 | **개인정보처리방침 URL** | 위치정보를 수집하므로 **활성 URL의 처리방침 링크가 필수**(스토어 등록정보 + 앱 내). projectyoon.com에 호스팅 가능 | 앱인토스/스토어 공통 요건 |
| B4 | **위치정보 이용 동의** | 앱 진입 시 위치정보 수집·이용 동의 흐름. 사업 신고는 됐으나 앱 내 동의 UI 필요 | 위치정보법 |
| B5 | **앱인토스 SDK 래핑** | 현재 순수 Expo(expo-router). 미니앱은 **앱인토스 RN SDK/WebView**로 감싸야 함 → 진입점·빌드 구성 작업 | 앱인토스 개발 방식 |

## 🟡 출시 전 권장

- 앱 아이콘 · 스플래시 · 스토어 스크린샷 (실사 스타일 + 앱 팔레트)
- 이용약관
- 빈 데이터 지역(서울·부산 등 이름 없는 카드) 품질 — 카카오키+CSV 지오코딩으로 개선 진행 중

## 🟢 안 해도 되는 것 (현재 범위)

- **토스 로그인/토스페이/인앱결제** — 무료 유틸이라 불필요. (붙이면 심사 항목만 늘어남)
- 생성형 AI 고지 — 해당 없음

---

## 우선순위 로드맵

1. **[B1] 번들 용량 해결** — 기술 blocker. 이거 안 풀면 미니앱 심사 자체가 어려움
2. **[B3][B4] 개인정보처리방침 + 위치동의** — 정책 필수, 병렬 가능
3. **[B2] 외부 링크(카카오맵) 검토** — 앱인토스에 문의 or 인앱 대체
4. **[B5] 앱인토스 SDK 래핑** — 위 정리 후 마지막 통합
5. 아이콘·스크린샷 → **심사 신청**

## ⚠️ 작업 조율 주의

이 레포는 **여러 세션이 동시에 개발 중**일 수 있음. 특히 B1(번들/데이터 레이어)은 데이터 파이프라인 세션과 겹치므로, 착수 전 어느 세션이 맡을지 정하고 `git pull` 먼저 할 것.
